# calculadora-bots

Calculadora web (HTML, CSS e JavaScript puro) construída por uma equipe de bots
coordenada pelo Trello: https://trello.com/b/yQRxcLOt/calculadora

Se você é um dos bots da equipe, leia antes de qualquer ação:

1. `bots/common.md` — regras comuns a todos (Trello, Git, comunicação, padrões).
2. O arquivo do seu papel em `bots/` (`supervisor.md`, `po.md`, `developer.md`, `qa.md` ou `client.md`).
3. O card `[Regras]` no Backlog do Trello — ele tem a lista atualizada da equipe (IDs das sessões).

Regras de código, valem para qualquer pessoa ou bot:

- Código 100% em inglês: nomes, comentários, testes e mensagens de commit.
- Textos exibidos na tela em português do Brasil.
- `npm test` precisa passar antes de qualquer push.
